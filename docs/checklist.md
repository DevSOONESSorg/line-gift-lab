# 職員用 動作チェックリスト

参加者に使ってもらう前に、職員が自分のPCで一度ぜんぶ通すためのリストです。
上から順にやれば、1回目は2〜3時間、2回目以降は1時間ほどで終わります。

- 表の「期待する結果」と違ったら、その行の番号と画面（またはターミナルの最後の数行）を控えておく
- 途中で壊れたら、[12. リセット](#12-片付けとリセット) で最初からやり直せる
- 別のタブで [裏側ビュー](http://localhost:3000/inside) を開いたままにすると、原因を追いやすい
