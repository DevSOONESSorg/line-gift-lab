# コースB：公式LINEを自分で作れる

コースAでは、疑似LINEの中で「しくみ」を理解しました。コースBでは **本物のLINE** を使って、自分の公式アカウントを作り、設定していきます。

| 段階 | 内容 | コード | 目安 |
|---|---|---|---|
| [B0 準備](B0-junbi.md) | アカウントを用意する・注意事項 | なし | 15分 |
| [B1 公式アカウント](B1-account.md) | 公式アカウントを作り、あいさつ・応答メッセージを設定する | なし | 30分 |
| [B2 リッチメニュー（Manager）](B2-richmenu-manager.md) | 画像を作り、1分割→6分割のリッチメニューを作る | なし | 60分 |
| [B3 Webhook](B3-webhook.md) | Messaging API を有効にし、自分のPCの bot とつなぐ | 少し | 60分 |
| [B4 リッチメニュー（API）](B4-richmenu-api.md) | プログラムでリッチメニューを作る（postback・タブ切り替え・人ごと） | 少し | 60分 |
| [B5 LIFF](B5-liff.md) | リッチメニューから教材アプリの「贈る」画面を開き、本物のLINEで買う | 少し | 60分 |
| [B6 発展](B6-hatten.md) | 要件変更カード | あり | 早く進んだ人 |
| [B9 片付け](B9-katazuke.md) | 作ったものを削除する | なし | 10分（**必ずやる**） |

**全員が B2 まで** できれば十分です。B1〜B2 は、運営スタッフがオリジナルのお店の公式LINEを構築するときの設定（あいさつ文・リッチメニュー）と同じ作業です。コースBでは、あなたがオーナー役（公式アカウントを持つ人）と運営スタッフ役（設定する人）を兼ねます。

## コースAとのちがい

| | コースA | コースB |
|---|---|---|
| LINE | 疑似LINE（教材アプリの中） | 本物のLINE |
| スマホ | 疑似スマホ | 自分のスマホ |
| プロバイダー | 運営のプロバイダー（会社の箱） | **自分で作ったプロバイダー**（会社の箱には入れない） |
| 自社サーバー | localhost | localhost ＋ トンネル（インターネットからの入口） |

> 実際の仕事では、会社のアカウントで・会社のプロバイダーを選んで有効化します。コースBは体験なので、**会社のプロバイダーや本番のチャネルには一切さわりません**。

## 提出するもの

段階ごとに、次を提出してください。

1. **スマホの画面キャプチャ**（リッチメニューが出ているトーク画面、botが返事をしている画面など）
2. **作業報告（3行）**：何を設定したか ／ どう確認したか ／ 難しかったところ
3. B3 以降でコードを変えた人は、`git diff > kadaiB3.txt` のように変更内容を保存して提出

> スクリーンショットに **チャネルシークレット・アクセストークンが写らないように** 注意してください。
