# B0 準備

## 1. アカウントを用意する（どちらか）

公式アカウントを作るには、LINEの「ビジネスID」でログインする必要があります。次のどちらかを選んでください。

| 方法 | こんな人に | メモ |
|---|---|---|
| **A. 自分のLINEアカウントでログイン** | ふだん使っているLINEで試してよい人 | いちばん簡単。作った公式アカウントは、体験のあと削除します（B9） |
| **B. メールアドレスで体験用のビジネスIDを作る（捨て垢）** | 自分のLINEを使いたくない人 | 体験用のメールアドレス（フリーメールで可）を1つ用意。LINEの個人アカウントは作らなくてよい |

> 方法B で「個人のLINEアカウント」をもう1つ作るのはおすすめしません（別の電話番号が必要になるため）。**ビジネスIDだけをメールアドレスで作る** のが「捨て垢」の作り方です。

方法B の手順（画面の文言は変わることがあります）：

1. <https://account.line.biz/> を開く
2. **アカウントを作成** →「**メールアドレスで登録**」を選ぶ
3. 体験用のメールアドレスを入れ、届いたメールのリンクから、名前とパスワードを登録する

## 2. スマホを用意する

公式アカウントを友だち追加して、動きを確かめるのに使います。

- 方法A の人：ふだんのLINEで友だち追加します（体験後にブロック・削除できます）
- 方法B の人：友だち追加だけは、手元のスマホのLINEでします（友だち追加しても、相手に自分の個人情報は渡りません。公式アカウントからは表示名とアイコンが見えます）

## 3. 約束ごと（必ず守る）

- **会社のプロバイダーや、実際の店舗のチャネルは選ばない・さわらない**（体験では自分で作ったものだけを使う）
- **チャネルシークレット・アクセストークンは、人に見せない・スクショに写さない・GitHubに上げない**
- 公式アカウントの名前に、実在のお店や会社の名前を使わない（例：「山田の体験カフェ」）
- 無料プラン（コミュニケーションプラン）は、**こちらから送るメッセージ（push）が月200通まで** です。返信（reply）と応答メッセージは数えられません。体験の範囲なら足ります
- 体験が終わったら **B9 片付け** を必ずやる

## 4. 教材アプリ

B1・B2 は教材アプリがなくてもできます。B3 以降は教材アプリを使います。
