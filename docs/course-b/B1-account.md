# B1 公式アカウントを作る

> コースA 第3章①・第7章 の本物版です。

## やること

### 作る

1. <https://manager.line.biz/> を開き、B0 で決めた方法でログインする
2. **作成**（または「LINE公式アカウントを作成」）を押す
3. 入力する

   | 項目 | 入れる値 |
   |---|---|
   | アカウント名 | 体験用の名前（例：山田の体験カフェ） |
   | メールアドレス | 自分の（または体験用の）メールアドレス |
   | 所在国・地域 | 日本 |
   | 業種 | それらしいもの（例：飲食） |
   | 運用目的・主な使い方 | それらしいもの |

4. 内容を確認して **完了**。Manager のホームが開けばOK
5. **設定 → アカウント設定** で **ベーシックID（@xxx）** を確認する

### 友だち追加する

6. ホームの「友だちを増やす」（または「友だち追加ガイド」）にある **QRコード** を、スマホのLINEで読み取って友だち追加する
7. スマホに **あいさつメッセージ** が届く

### あいさつと応答メッセージを変える

8. 左メニューの **あいさつメッセージ** で文面を自分のお店らしく書きかえて保存 → スマホで一度ブロック→ブロック解除すると、もう一度届く
9. **応答メッセージ**（または「自動応答メッセージ」）で、キーワード `営業時間` に反応する応答を作る（例：「11:00〜22:00 です」）
10. スマホから `営業時間` と送る → 設定した文が返ってくる。ほかの言葉を送ると？

### 応答設定を見てみる

11. **設定 → 応答設定** を開き、「チャット」「あいさつメッセージ」「Webhook」「応答メッセージ」の項目を確認する

## 考えてみよう

- **チャット** をオンにすると、スマホから送ったメッセージに、Manager の「チャット」画面から人が手で返事ができます。試してみましょう
