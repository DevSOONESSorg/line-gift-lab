# B6 発展：要件変更カード

早く進んだ人向けです。お店から、こんな要望が来たという設定です。**要件を整理 → どのファイルを変えるか決める → 実装 → 本物のLINEで確認 → 報告** の順で進めてください。AI に相談してかまいません。コードの読み方は [コースC](../course-c/README.md) も参考に。

| カード | 要望 | ヒント |
|---|---|---|
| 1 | 「リッチメニューの"予約"ボタンを押したら、日付を選べるようにしてほしい」 | postback アクションの `"mode": "datetime"`（datetimepicker）。bot 側は `$event['postback']['params']['datetime']` |
| 2 | 「返事を文字だけじゃなく、ボタン付きのカードにしてほしい」 | Flex Message。`LineClient` は今テキストしか送れないので、`messages` をそのまま渡せる関数を足す |
| 3 | 「ギフトが届いたら、お店の公式LINEにも通知がほしい（運営LINEだけだと見落とす）」 | `Notifier::toOwner()` で、店舗専用チャネルが使えるならそちらからも送る。オーナーがお店の公式LINEの友だちでないと届かない点に注意 |
| 4 | 「1回でも贈ってくれた人には、特別なリッチメニューを出したい」 | 注文ができたときに、その人に `lab:richmenu link` と同じ API（`/v2/bot/user/{userId}/richmenu/{id}`）を呼ぶ |
| 5 | 「LIFF のユーザーIDをそのまま信じるのは危ないと聞いた」 | コースC の C4-3（IDトークンの検証） |
