# B2 リッチメニューを作る（Manager）

> コースA 第8章 の本物版です。実際の店舗でいちばんよく頼まれる作業です。

## 1. まず1分割（1ボタン）

1. 背景画像を用意する：教材アプリのテンプレート <http://localhost:3000/samples/templates/> から `small-1_2500x843.png` をダウンロード（教材アプリがない人は、GitHub の `public/samples/templates/` からダウンロード）
2. Manager → 左メニュー **リッチメニュー** → **作成**
3. **タイトル**（管理用）と **表示期間**（今日〜1か月後など）を入れる
4. **テンプレートを選択** →「小」の1分割を選ぶ
5. **背景画像をアップロード** で、用意した画像を選ぶ
6. **アクション**：タイプ **テキスト**、文字 `営業時間`（B1 で作ったキーワード応答が返ってくる）
7. **メニューバーのテキスト**、**メニューのデフォルト表示：表示する** を確認して **保存**
8. スマホでトークを開き直す → リッチメニューが出て、押すと `営業時間` が送られて返事が来ればOK

## 2. 自分で画像を作って 6分割

1. `large-6_2500x1686.png` をダウンロードし、Canva などで A〜F の場所にボタンの絵や文字を入れる
   - **画像のサイズ（2500×1686）は変えない**
   - 1MB 以下で保存する（PNG が重いときは JPEG にする）
   - 文字は大きめに。スマホの画面では小さく見えます
2. **作成** →「大」の6分割を選び、画像をアップロード
3. ボタンごとにアクションを決める（例）

   | ボタン | タイプ | 中身 |
   |---|---|---|
   | A | テキスト | `営業時間` |
   | B | リンク | お店の地図（Googleマップの共有URL） |
   | C | リンク | Webサイト（なければ `https://example.com/`） |
   | D | クーポン | Manager で作ったクーポン（左メニュー「クーポン」で先に作る） |
   | E | テキスト | `予約したい` |
   | F | 設定しない | 飾り |

4. 保存し、スマホで確かめる。**新しいメニューを表示したいときは、古いメニューの表示期間や「表示する」の設定を確認**（同じ期間に複数あると、どれが出るか迷います）

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 画像がアップロードできない | サイズがテンプレートと合っているか（2500×1686 など）・1MB 以下か |
| 押す場所と絵がずれる | テンプレートと画像の分割が合っているか |
| スマホに出ない | 表示期間に今日が入っているか・デフォルト表示が「表示する」か・トークを開き直したか |
