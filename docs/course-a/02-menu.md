# 第2章 商品と手数料・掲載方法を確認する

> 手順書 第2章に対応 ／ 使う画面：管理画面（運営スタッフ）
>
> この章でわかること：購入には商品が必須 ／ 手数料は注文のときに計算される ／ 共通掲載とオリジナルのちがい

## やること

1. [店舗管理](http://localhost:3000/admin/stores) → 自分の店名をクリックして **店舗詳細** を開く
2. 「商品一覧」に、第1章でオーナーが登録した商品が並んでいるか確認する。なければ、オーナーの代わりに **＋ 追加** で1つ以上登録する
3. **編集** →「管理設定」の **デフォルト手数料率** を入れる（例 10）
4. 同じカードの **共通掲載** のチェックを確認する（オリジナルを選んだお店は外れている）→ 最下部の **更新**

店舗詳細の「商品一覧」に商品が1つ以上並んでいればOKです。

## なぜ？

**Q. 手数料率って何？**
お客さんが払った金額のうち、サービス運営（おくりギフト）が受け取る割合です。1,000円のギフトで手数料率10%なら、100円が運営の取り分、残りがオーナーの口座への振込対象になります。

手数料は **注文が入ったときの手数料率で計算して、注文に保存** します。あとで手数料率を変えても、過去の注文の手数料は変わりません（[注文詳細](http://localhost:3000/admin/orders) に「注文時の手数料率」が出ます）。

**Q. 共通掲載とオリジナルは何がちがう？**

| | 共通掲載 | オリジナル |
|---|---|---|
| お客さんの入口 | 運営の公式LINE「ギフトを贈る」の一覧 | お店の公式LINEのリッチメニュー |
| お店の公式LINE | いらない | オーナーが用意し、運営が設定する（第3〜8章） |
| 運営の作業 | 承認・手数料だけ | ＋ 公式LINEの構築 |

共通掲載のチェックを入れたお店だけが、運営の公式LINEの「ギフトを贈る」に並びます。試しに見本フラワーの共通掲載を外すと、一覧から消えます（確かめたら戻す）。

**Q. 「身分証提示を必須」は？**
同じ「管理設定」カードのオプションです。必須にすると、贈る画面に「身分証の画像」欄が出ます（お酒を出すお店などで使います）。第10章で試してみましょう。

## 壊してみよう（あとで必ず元に戻す）

第10章まで終わってから、商品を全部削除して、贈る画面を開いてみましょう。「このお店にはまだ商品がありません」と出て、購入できません。手順書に「これが無いと購入できません」と書いてある理由です。
