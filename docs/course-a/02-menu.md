# 第2章 商品・手数料・掲載方法を確認する

> 手順書 第2章に対応 ／ 使う画面：管理画面（運営スタッフ）
>
> この章でわかること：購入には商品が必須 ／ 手数料は「注文した時点の率」で計算して保存 ／ 月別手数料率 ／ 共通掲載とオリジナル

## やること

1. [店舗管理](http://localhost:3000/admin/stores) → 自分の店名 → **店舗詳細**
2. 「メニュー一覧」に、第1章でオーナーが登録した商品が並んでいるか確認（なければ **+ 追加** でオーナーの代わりに入れる）
3. **編集** →「管理設定」の **デフォルト手数料率** を入れる（例 15）→ **更新**
4. 同じ画面の下の **月別手数料率** で、来月だけ別の率（例 10）を入れて **月別手数料率を保存**
5. 「共通アプリの店舗一覧に掲載する」がオフ（オリジナルを選んだため）になっているのを確認

## なぜ？

**Q. 手数料率って何？**
お客さんが払った金額のうち、運営（おくりギフト）が受け取る割合です。1,000円のギフトで15%なら、150円が運営、850円がお店への振込額になります。

**Q. 月別手数料率は何のため？**
「開店キャンペーンで最初の3か月は10%」のように、月ごとに率を変えるためです。月別の設定がない月は、デフォルト手数料率が使われます。
→ `app/Services/CommissionService.php` の `rateFor()` の3行がその決まりです。

**Q. あとで手数料率を変えたら、過去の注文は？**
変わりません。注文を作るときに、その時点の率と手数料を `orders.commission_rate` と `orders.commission` に**保存**しているからです（[注文詳細](http://localhost:3000/admin/orders) の「手数料率（注文時点）」）。お金の記録は、あとから計算し直さずに「その時の値」を残すのが基本です。

**Q. 共通掲載とオリジナルは何がちがう？**

| | 共通掲載 | オリジナル |
|---|---|---|
| お客さんの入口 | 運営の公式LINE「お店をさがす」 | お店の公式LINEのリッチメニュー／お店のQR |
| お店の公式LINE | いらない | オーナーが用意し、運営が設定する（第3〜8章） |
| お知らせの送り元 | 運営の共通チャネル | お店のチャネル（未設定なら共通チャネル） |

オフにしても、**お店専用のURL・QRからは贈れます**（検索に出なくなるだけ）。試しに見本バーの掲載をオフにすると「お店をさがす」から消えます（確かめたら戻す）。

**Q. 「身分証提示を必須」は？**
オンにすると、まだ身分証を登録していないお客さんに画像のアップロードを求めます。**一度登録した身分証は、ほかのお店でも有効**です（身分証は「お客さん」に付く情報で、「お店」に付く情報ではないため）。

## 壊してみよう（あとで戻す）

第10章のあとで、オーナー役で商品を全部「停止」にして、贈る画面を開いてみましょう。「このお店にはまだ商品がありません」と出て、贈れません。
