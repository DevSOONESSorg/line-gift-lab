# 第11章 障害ドリル ／ 困ったときの見る場所 ／ 通しチェック

## 障害ドリル

職員が、あなたのお店の設定を **どこか1か所だけ** こっそり壊します。あなたには「症状カード」だけが渡されます。原因を探して直してください。

### 進め方

1. 症状カードを読む（例：「トークで話しかけても、botが返事をしない」）
2. 疑似スマホで症状を再現する
3. [裏側ビュー](http://localhost:3000/inside) で **NG** の行を探す（絞り込み →「NGだけ」）。行を開いて中身を読む
4. 下の「困ったときの見る場所」の表を使って、どこを直すか決める
5. 直したら、もう一度疑似スマホで確かめる
6. 報告を書く（症状 ／ どこを見てわかったか ／ どう直したか）

> NG が出ないこともあります。そのときは「どこまで届いているか」を見ます。スマホの行はあるのに LINE社の行がない？ LINE社の行はあるのに自社サーバーの行がない？

## 困ったときの見る場所

| 症状 | 見るところ |
|---|---|
| メッセージを送っても bot が返さない | Webhook の Verify が 200 か ／ 応答設定が Bot・Webhook＝オン か ／ Webhook URL の slug が正しいか ／ 署名NG（シークレット）が出ていないか |
| 返事が2通来る | 応答設定の応答メッセージがオフか |
| 「トークンが無効です」（401）・テスト送信の失敗 | アクセストークンを再発行したか → 管理画面の値を更新 |
| 「贈る」でちがうお店が開く | LIFF のエンドポイントURL の slug |
| 「準備中」と出る | 管理画面の「承認済み」 |
| 共通掲載の一覧にお店が出ない | 「承認済み」と「共通掲載」の両方にチェックがあるか |
| 購入画面に商品がない | オーナーの商品登録（店舗詳細の商品一覧） |
| LIFFが開かない・「LIFF IDがありません」 | リッチメニューやQRの LIFF ID の打ち間違い |
| お知らせが届かない | 注文が来た道の公式アカウントと友だちか（ブロックしていないか） |
| 注文が「リクエスト中」のまま | おくりギフト(dev)→「店舗管理」→ 贈り物一覧 →「受け取る」まで必要 |
| （本物・本番）LIFF が一般の人に開けない | LINEログインチャネルが「公開」になっているか |

## 通しチェック（これが全部できれば完了）
