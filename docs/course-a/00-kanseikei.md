# 第0章 完成形を触ってみる

> この章でわかること：このコースのゴール（全部つながった状態）が、お客さんからどう見えるか

教材アプリには、最初から **「見本カフェ」** という、全部の設定が終わったお店が入っています。まずはお客さんになって、見本カフェのギフトを買ってみましょう。

## やること

1. [疑似スマホ](http://localhost:3000/mock/phone) を開く
2. 友だち一覧の **見本カフェ** を押してトークを開く
3. 下に出ているリッチメニュー **「ギフトを贈る」** を押す
4. スマホの中に「見本カフェ」の贈る画面が開く
5. メニューを選び、宛先（例：山田さん）を入れて、テストカードで支払う

   | 項目 | 入れる値 |
   |---|---|
   | カード番号 | `4242 4242 4242 4242` |
   | 有効期限 | `12/40`（今日より先ならなんでもOK） |
   | CVC | `123`（3桁ならなんでもOK） |

6. 「ありがとうございました」の画面が出たら、左上の **✕ 閉じる** でトークに戻る
7. 見本カフェから「贈り物を受け付けました」とメッセージが届いているのを確認する

## 裏側を見る

[裏側ビュー](http://localhost:3000/inside) を開いてみましょう。いまの数十秒のあいだに、これだけのことが起きています（下から上へ、古い順）。

| だれ | 何をした |
|---|---|
| LINE社 | 「LIFF ○○ を開きます → エンドポイントURL …/liff/s/sample-cafe」 |
| 自社サーバー | 贈る画面を表示した |
| 自社サーバー | 注文を受け付けた → 状態「リクエスト中」 |
| 自社サーバー | LINEにお願い（push）… 買った人にお知らせを送って |
| LINE社 | 見本カフェからメッセージを届けた |
| 自社サーバー／LINE社 | 運営の公式LINEから店舗管理者にお知らせ … **NG（届いていません）** |

最後の NG は、あなた（見本カフェの店舗管理者）が、まだ運営の公式LINE「おくりギフト(dev)」と友だちになっていないからです。第1章で友だちになると届くようになります。
