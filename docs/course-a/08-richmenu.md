# 第8章 リッチメニューの「贈る」ボタンをつなぐ

> 手順書 第8章に対応 ／ 使う画面：Manager・スマホ
>
> この章でわかること：リッチメニュー＝「1枚の画像」＋「押せる場所（座標）」 ／ ボタンの行き先（アクション）だけを変える ／ LIFF の URL の形

お店はもう、自分のリッチメニューを使っています。運営スタッフの仕事は、**そのメニューはそのままで、「ギフトを贈る」ボタンの行き先だけを、贈る画面（LIFF）の URL にすること** です。

> 構築ナビの手順14にあたります。お店によって「贈る」ボタンの場所と名前（「シャンパンを贈る」「推しに贈る」など）がちがいます。構築ナビに、そのお店のボタンの記号（A・B…）と名前が出ます

## やること（いまあるメニューの「贈る」ボタンをつなぐ）

0. 本番では、リッチメニューを **誰が設定するか**（運営か、お店か）を先に確認します。この課題は運営が設定します
1. Manager（会社の作業アカウント）→ **クラブ アズール** → 左メニュー **リッチメニュー**
2. 表示中の「お店のメニュー」の **編集** を押す
3. 画像の上に A〜D の枠が出る。**A が「ギフトを贈る」**（今は「設定しない」）。B〜D はお店が使っているボタン
4. A のタイプを **リンク** にし、URL に第4章で作った LIFF の **LIFF URL** を入れる。Dev Console の LINEログインチャネル → **LIFF** タブの「LIFF URL」から **コピー** して貼る（目で写さない）

   ```
   https://liff.line.me/{LIFF_ID}
   ```

5. B〜D は **触らない**（お店の情報・営業時間・Instagram はお店のもの。手順5で見ておいたとおりのまま）→ **保存**
   - ほかのボタンを変えてしまうと、構築ナビに「『ギフトを贈る』以外のボタンが、スタート地点から変わっています」と赤く出ます
6. 左の **お客さんのスマホ** でクラブ アズールのトークを開き、リッチメニューの **ギフトを贈る** を押す。贈る画面（LIFF）が開けば成功

## 裏側を見る

ボタンを押したとき：

- LINE社：**LIFF ○○ を開きます → エンドポイントURL …/liff/s/club-azure**
- 自社サーバー：LIFF画面「○○」の贈る画面を表示しました

## なぜ？

**Q. なぜ画像サイズが決まっているの？**
リッチメニューには「文字」や「ボタン」という部品はありません。**ただの1枚の画像** の上に、「左から○%・上から○%の四角を押したら、このURLを開く」という **見えない当たり判定** を重ねているだけです。テンプレートは、その四角の位置のセットです。画像の縦横の比率がずれると、絵と当たり判定がずれてしまうので、サイズが決められています。
→ 疑似スマホでリッチメニューの上にマウスを乗せると、当たり判定の四角と、設定したURLが見えます。

**Q. アクションの種類は？**

| タイプ | 押すと | 使いどころ |
|---|---|---|
| リンク | URLを開く | LIFF（贈る画面）、Webサイト |
| テキスト | その文字を、お客さんが送ったことにする | 「メニュー」と送らせて bot に答えさせる |
| 設定しない | 何も起きない | 飾りの部分 |

本物の Manager には、ほかに「クーポン」「ショップカード」などもあります。

**Q. リンクに、エンドポイントURLを直接入れてはだめ？**
だめです。`https://liff.line.me/{LIFF_ID}` で開くから、LINE社が「これはLIFFだ」とわかり、**開いた人の情報（プロフィール）を自社ページに渡せる** のです。

## 壊してみよう

| 実験 | 結果 |
|---|---|
| 編集で、A のリンクの LIFF ID の `I` を `l` に（または `O` を `0` に）1文字変えて保存 | 押すと「**システムエラー** LIFF app '…' was not found.」（本番で実際に起きたのと同じ。コピーで貼り直して保存） |
| B（お店の情報）を押してみる | テキスト「お店の情報」が送られ、お店のキーワード応答（住所・電話番号。下に小さく **応答メッセージ**）が返る。ギフトの案内（bot）は返らない（第7章で自社の自動返信をオフにしたから） |

最後は A を正しい LIFF の URL に戻しておきましょう。

## 発展：リッチメニューを新しく作る（今回はやらなくてよい）

本番では、お店にリッチメニューがないときや、ボタンを増やして配置を変えるときに、新しく作ることもあります。流れだけ知っておきましょう（リッチメニュー一覧の「作成」）。

| サイズ区分 | 画像サイズ（どれか1つ） |
|---|---|
| 大（Large） | 2500×1686 ／ 1200×810 ／ 800×540 px |
| 小（Small） | 2500×843 ／ 1200×405 ／ 800×270 px |

- 枠つきのテンプレート画像：<http://localhost:3000/samples/templates/>（A, B, C… がボタンの位置）
- タイトル・テンプレート・画像・各ボタンのアクションを入れ、「メニューのデフォルト表示：表示する」で保存

## もっと知りたい人へ

- 送信履歴（領収書）やお礼一覧のボタンを作るときは、**同じ LIFF URL の後ろに** `?action=send-history` ／ `?action=thanks` を付けます（例：`https://liff.line.me/{LIFF_ID}?action=send-history`）。本番と同じで、教材アプリでも使えます。見本のお店「シャンパンバー ルミエール」のメニューがこの形です
- Manager で作るリッチメニューは「全員に同じもの」です。人によってメニューを変えたり、タブで切り替えたりするには **Messaging API** で作ります → [コースB：B4](../course-b/B4-richmenu-api.md)
