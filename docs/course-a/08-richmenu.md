# 第8章 リッチメニューを作る

> 手順書 第8章に対応 ／ 使う画面：Manager・スマホ
>
> この章でわかること：リッチメニュー＝「1枚の画像」＋「押せる場所（座標）」 ／ 画像サイズが決まっている理由

## 先に：背景画像を1枚つくる（必須）

リッチメニューは **「1枚の背景画像」＋「分割（ボタン領域）」** でできています。画像は自分で用意し、選ぶテンプレートの分割・サイズに合わせて作ります（PNG または JPEG・1枚・1MBまで）。

| サイズ区分 | 画像サイズ（どれか1つ） |
|---|---|
| 大（Large） | 2500×1686 ／ 1200×810 ／ 800×540 px |
| 小（Small） | 2500×843 ／ 1200×405 ／ 800×270 px |

- 枠つきのテンプレート画像：<http://localhost:3000/samples/templates/>（A, B, C… がボタンの位置）
- 迷ったら **「小・1分割」**（`small-1_1200x405.png`）で、まず1ボタンから
- 余裕があれば、テンプレート画像をダウンロードして、Canva やプレビュー（Mac）・ペイント（Windows）で「贈る」などの文字を書き込む。**サイズは変えないこと**

## やること

1. Manager（会社の作業アカウント）→ 自分のお店 → 左メニュー **リッチメニュー** → **作成**
2. **タイトル**（管理用・お客さんには出ない）を入れる
3. **テンプレート** を選ぶ（選ぶと必要な画像サイズが表示される）
4. **画像** で、用意した背景画像を選ぶ
5. **アクション** のタイプを **リンク** にし、URL に LIFF のリンクを入れる（ボタンが複数なら各ボタンに設定）

   ```
   https://liff.line.me/{LIFF_ID}
   ```

6. **メニューのデフォルト表示：表示する** にチェック（トークを開いたときに出る）
7. **保存**
8. 疑似スマホでお店のトークを開き、下にリッチメニューが出ていればOK。押して「贈る」画面（LIFF）が開けば成功

## 裏側を見る

ボタンを押したとき：

- LINE社：**LIFF ○○ を開きます → エンドポイントURL …/liff/s/club-azure**
- 自社サーバー：LIFF画面「○○」の贈る画面を表示しました

## なぜ？

**Q. なぜ画像サイズが決まっているの？**
リッチメニューには「文字」や「ボタン」という部品はありません。**ただの1枚の画像** の上に、「左から○%・上から○%の四角を押したら、このURLを開く」という **見えない当たり判定** を重ねているだけです。テンプレートは、その四角の位置のセットです。画像の縦横の比率がずれると、絵と当たり判定がずれてしまうので、サイズが決められています。
→ 疑似スマホでリッチメニューの上にマウスを乗せると、当たり判定の四角と、設定したURLが見えます。

**Q. アクションの種類は？**

| タイプ | 押すと | 使いどころ |
|---|---|---|
| リンク | URLを開く | LIFF（贈る画面）、Webサイト |
| テキスト | その文字を、お客さんが送ったことにする | 「メニュー」と送らせて bot に答えさせる |
| 設定しない | 何も起きない | 飾りの部分 |

本物の Manager には、ほかに「クーポン」「ショップカード」などもあります。

**Q. リンクに、エンドポイントURLを直接入れてはだめ？**
だめです。`https://liff.line.me/{LIFF_ID}` で開くから、LINE社が「これはLIFFだ」とわかり、**開いた人の情報（プロフィール）を自社ページに渡せる** のです。

## 壊してみよう

| 実験 | 結果 |
|---|---|
| 大（Large）のテンプレートに、小の画像（1200×405）を選ぶ | 「画像サイズが合いません」と保存できない |
| リンクの LIFF ID を1文字変えて、新しいメニューとして保存 | 押すと「LIFF IDのLIFFアプリはありません」 |
| 「小・2分割」で、Bのボタンをテキスト `メニュー` にする | 押すと bot がメニューを返す |

作ったメニューが複数あるときは、リッチメニュー一覧の **これを表示する** で切り替えられます。最後は正しいメニューを表示に戻しておきましょう。

## もっと知りたい人へ

- 追加のボタン例：送信履歴（領収書）＝ `…?action=send-history` ／ お礼一覧 ＝ `…?action=thanks`（本物のサービスの例。教材アプリにはありません）
- Manager で作るリッチメニューは「全員に同じもの」です。人によってメニューを変えたり、タブで切り替えたりするには **Messaging API** で作ります → [コースB：B4](../course-b/B4-richmenu-api.md)
