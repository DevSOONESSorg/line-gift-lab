# 第7章 応答設定を整える

> 手順書 第7章に対応 ／ 使う画面：Manager・スマホ
>
> この章でわかること：返事をするのは「LINE社の定型文」と「自社のbot」の2種類 ／ 応答メッセージを OFF にする理由

この章は、**先に壊れた状態（手順書の設定をする前）を体験** してから直します。

## やること

### まず、いまの状態で話しかけてみる

1. [疑似Manager](http://localhost:3000/mock/manager)（会社の作業アカウント）→ 自分のお店 → ホームの **疑似スマホで友だち追加** → **追加**
2. トークに届いたメッセージを見る（あいさつメッセージ ＋ botからの返事）
3. `こんにちは` と送る → **返事が2通** 来る
   - 「メッセージありがとうございます！申し訳ありませんが…」（下に小さく **応答メッセージ**）
   - 「こんにちは！ご来店お待ちしています。」（下に小さく **bot**）
4. `メニュー` と送る → botがメニューを返す。ほかの言葉はオウム返し

### 手順書どおりに直す

5. Manager → 自分のお店 → **応答設定**
6. **応答モード＝Bot** ／ **Webhook＝オン** ／ **応答メッセージ＝オフ** にして **保存**
7. もう一度 `こんにちは` と送る → 返事は **bot の1通だけ** になる

## 裏側を見る

3 のときの裏側ビュー：

- スマホ：「こんにちは」と送信しました
- LINE社：**応答メッセージ（定型文）を自動で返しました**
- LINE社：Webhook送信 [message] → 200
- 自社サーバー：Webhook受信 → 署名OK：message「こんにちは」
- 自社サーバー：LINEにお願い POST /v2/bot/message/reply → 200

LINE社と自社サーバーが、**それぞれ勝手に返事をしている**ことがわかります。

## なぜ？

**Q. 応答メッセージと bot のちがいは？**

| | 応答メッセージ | bot（Webhook） |
|---|---|---|
| 返事をするのは | LINE社 | 自社サーバー |
| 中身 | Manager に書いた決まった文 | プログラム（[storeBot.js](../../src/app/bot/storeBot.js)）で考えた文 |
| 設定する場所 | Manager の応答設定 | 自社のプログラム |

公式アカウントを作った直後は、応答メッセージが **オン** になっています。自社のbotとつなぐときは、**オフにしないと両方が返事をして混ざる** のです。

**Q. 応答モード「チャット」にするとどうなる？**
「人が手で返事をする」モードになり、LINE社は Webhook を送らなくなります。試してみましょう（裏側ビューに「メッセージを自社サーバーに送りません（応答モードが「チャット」になっている）」と出ます）。確かめたら Bot に戻します。

**Q. Manager の「Webhook」と Dev Console の「Use webhook」はちがうもの？**
同じ1つのスイッチです。どちらで切り替えても、もう片方も変わります。

**Q. 友だち追加したとき2通来たのは？**
「あいさつメッセージ」（LINE社）と、follow イベントへの bot の返事（自社）です。どちらを使うかはお店と相談して決めます（片方をオフにすることが多い）。

2. botが1通も返事をしません。応答設定で確認するところを3つ挙げてください。
