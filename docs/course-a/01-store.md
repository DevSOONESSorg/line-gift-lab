# 第1章 出店登録・商品登録（オーナー）と承認（運営）

> 手順書 第1章に対応 ／ 使う画面：スマホ（オーナー役）・管理画面（運営スタッフ）
>
> この章でわかること：お店はオーナーが「LINEから」申し込む ／ 口座登録・商品登録はオーナーの仕事 ／ slug とは何か ／ 承認の意味

## やること

### 管理画面を眺める（運営スタッフ）

1. [管理画面](http://localhost:3000/admin) を開く
2. 左メニューに **店舗管理・注文管理・ユーザー管理・売上集計・代理店管理** が並んでいるのを確認する（これが運営の操作盤）
3. 左下に **「LINE友だち登録」のQRコード** があります。お店のオーナーに読み取ってもらう、出店の入口です

### オーナーになって、出店登録する

4. QRの下の **「疑似スマホで読み取る」** を押す（本物では、オーナーが自分のスマホのLINEでQRを読み取ります）
5. 「おくりギフト(dev)」が表示されたら **追加**（すでに友だちなら、そのままトークが開きます）
6. リッチメニューの **出店登録** を押し、次を入力して **送信**

   | 欄 | 入れる値 |
   |---|---|
   | ユーザー登録 | オーナーのお名前・電話番号（体験用の値でOK） |
   | お店の情報 | 店名（例：クラブ アズール） |
   | 口座登録 | 銀行名・支店名・種別・口座番号（7桁）・名義。**本物の口座は入れない**（例 1234567） |
   | 掲載方法 | **オリジナル** を選ぶ（このコースでは第3〜8章で公式LINEを構築するため） |

7. 続けて **商品を登録する** → 商品名と価格を入れて **追加する**（2つ以上あると、あとの体験がわかりやすい。例：乾杯ドリンク 1,000円 ／ ボトル 5,000円）

### 運営スタッフに戻って、承認する

8. 管理画面の [店舗管理](http://localhost:3000/admin/stores) を開くと、いま登録したお店が **「未承認」** で増えている
9. その行の **編集** を開き、「オーナー・口座」カードで **口座が登録されているか** を確認する
10. 右側「管理設定」の **承認済み** にチェックを入れる
11. 左側「基本情報」の **スラッグ** を、自分で決めた slug に変える（例 `club-azure`）
12. 一番下の **更新** を押す。店舗管理に戻るとステータスが「承認済み」になっている

> 登録直後の slug は `store-3` のような仮の値です。本物の仕事でもここで slug を確定させます。**slug は一度決めたら変えません**（理由は下の「なぜ？」）。

## 裏側を見る

[裏側ビュー](http://localhost:3000/inside) で、次の流れを探してみましょう。

1. LINE社：LIFF ○○ を開きます → エンドポイントURL …/liff/platform/register
2. 自社サーバー：出店登録を受け付けました（未承認・オリジナル公式LINE希望）… **オーナー：LINEユーザーID U…** ／ 口座 ****567
3. 自社サーバー：オーナーが「○○」に商品「○○」を登録しました
4. 管理画面：店舗「○○」を更新しました（承認・slug）

## なぜ？

**Q. なぜお店は、管理画面からではなくLINEから登録するの？**
オーナーの **LINEユーザーID** を手に入れるためです。LINEの中の出店登録画面から送信すると、「誰が送ったか」（ユーザーID）がいっしょに届きます。自社サーバーはそのIDを「このお店のオーナー」として保存します。あとで贈り物が届いたとき、この人のLINEにお知らせを送ったり、「受け取る」や「商品登録」ができる人を決めたりするのに使います。

→ [疑似スマホのホーム](http://localhost:3000/mock/phone) に出ている「あなたのユーザーID」と、[ユーザー管理](http://localhost:3000/admin/users) の「お店のオーナー」のIDが同じことを確かめましょう。

**Q. 口座登録は何のため？**
お客さんが払ったお金（から手数料を引いた分）を、お店に振り込むためです。だから運営は、承認する前に口座が登録されているかを確認します。口座番号は大事な情報なので、管理画面では下3桁しか表示しません。

**Q. 商品登録は誰の仕事？**
**オーナー** です。お店の商品や値段はお店が決めるので、オーナーが店舗管理から自分で登録します（管理画面からも追加できますが、それは運営が代わりに入れるとき）。

**Q. slug（スラッグ）って何？**
URLの中に入る「お店の住所」です。このあと、次のURLに入ります。

| どこで使う | URL |
|---|---|
| 贈る画面（LIFFのエンドポイントURL） | `http://localhost:3000/liff/s/club-azure` |
| Webhook URL | `http://localhost:3000/api/webhook/line/store/club-azure` |

自社サーバーは、URLの slug を見て「どのお店の話か」を判断します。**あとで slug を変えると、LINE社に登録したURLと食いちがい、つながらなくなります。** だから「一度決めたら変えない」のです（第6章で実際に壊して確かめます）。

**Q. なぜ「承認」があるの？**
誰でもLINEから申し込めるので、運営が中身（お店の情報・口座）を確認してから公開するためです。未承認のお店は、共通掲載の一覧に出ず、贈る画面を開いても「準備中」になります。
