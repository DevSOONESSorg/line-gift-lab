# 第1章 出店登録・商品登録（オーナー）と承認（運営）

> 手順書 第1章に対応 ／ 使う画面：オーナーのスマホ（右）・管理画面（運営スタッフ）
>
> この章でわかること：お店はオーナーが「LINEから」申し込む ／ 振込先・商品はオーナーが入れる ／ slug とは何か ／ 承認の意味

## やること

### 管理画面を眺める（運営スタッフ）

1. [管理画面](http://localhost:3000/admin) にログイン（`admin@example.com` ／ `Taiken-2026`）
2. 左メニューの **ダッシュボード・店舗管理・注文管理・ユーザー管理・売上集計・商品テンプレート・代理店管理** を順に開いて眺める
3. 左下に **「LINE友だち登録」のQRコード** があります。お店のオーナーに読み取ってもらう、出店の入口です
4. 右下の **DEV** の表示も確認。本物の管理画面では、本番は **PROD** と出ます（本番を触っていないか、いつも目で確かめる）

### オーナーになって、出店登録する

5. QRの下の **「オーナーのスマホで読み取る」** → 右のスマホで おくりギフト(dev) を追加（すでに友だちならトークが開く）
6. リッチメニューの **出店登録** を押し、入力して **送信**

   | 欄 | 入れる値 |
   |---|---|
   | お店の情報 | 店名（例：クラブ アズール）・所在地・電話番号 |
   | 代表者 | お名前・電話番号（体験用の値でOK） |
   | 振込先 | 銀行名・支店名・種別・口座番号（7桁）・名義。**本物の口座は入れない**（例 1234567） |
   | 掲載方法 | **オリジナル** を選ぶ（このコースでは第3〜8章で公式LINEを構築するため） |

7. そのまま **商品登録** の画面になる。**テンプレートから追加**（例：スタッフ乾杯用）と、**自由に追加**（例：ボトル 5,000円）で2つ以上登録する

### 運営スタッフに戻って、承認する

8. 管理画面の [店舗管理](http://localhost:3000/admin/stores) に、いま登録したお店が **未承認** で増えている（ダッシュボードにも「1件 未承認」）
9. **編集** を開き、「代表者情報」「振込先情報」が入っているか確認する
10. **スラッグ** を自分で決めた slug に変える（例 `club-azure`）
11. 「管理設定」の **承認済み** をオンにして、下の **更新**
12. 店舗管理の一覧に戻り、ステータスが **承認済み** になっているのを確認

> 一覧の **承認／取消** ボタンからも切り替えられます。押すと「本当に？」と確認が出ます（取り返しのつかない操作には確認を出す）。

## なぜ？

**Q. なぜお店は、管理画面からではなくLINEから登録するの？**
オーナーの **LINEユーザーID** を手に入れるためです。LINEの中の出店登録画面から送信すると、「誰が送ったか」がいっしょに届きます。自社サーバーはそれを `stores.owner_line_user_id` に保存し、「このお店のオーナー」として使います（ギフトのお知らせを送る相手、「受け取る」を押せる人）。
→ [疑似スマホ](http://localhost:3000/mock/phone) の **右（オーナー）** のホームにある「ユーザーID」と、店舗詳細の「管理者（オーナー）」の LINE ID が同じことを確かめましょう。左（お客さん）のユーザーIDとは違います。

**Q. 振込先は何のため？**
お客さんが払ったお金から手数料を引いた分を、お店に振り込むためです。だから運営は、承認する前に振込先を確認します。口座番号は大事な情報なので、店舗詳細では下3桁しか表示しません。

**Q. 商品テンプレートって？**
運営が用意する「よくある商品」の見本です（[商品テンプレート](http://localhost:3000/admin/menu-templates)）。オーナーはそこから選んで、値段だけ変えれば登録できます。入力の手間と、商品名のばらつきが減ります。

**Q. slug（スラッグ）って何？**
URLの中に入る「お店の住所」です。

| どこで使う | URL |
|---|---|
| 贈る画面（LIFFのエンドポイントURL） | `http://localhost:3000/liff/s/club-azure` |
| Webhook URL | `http://localhost:3000/api/webhook/line/store/club-azure` |

自社サーバーは、URLの slug を見て「どのお店の話か」を判断します。**あとで slug を変えると、LINE社に登録したURLと食いちがい、つながらなくなります**（第6章で実際に壊して確かめます）。

**Q. なぜ「承認」があるの？**
誰でもLINEから申し込めるので、運営が中身（お店の情報・振込先）を確認してから公開するためです。未承認のお店は、共通掲載の一覧に出ず、贈る画面を開いても「準備中」になります。
