# 第9章 代理店をつくって店舗に紐付ける

> 手順書 第9章に対応 ／ 使う画面：管理画面
>
> この章でわかること：代理店＝お店を紹介してくれる人 ／ 1次・2次のしくみ

## やること

1. [代理店管理](http://localhost:3000/admin/agents) → 右上 **新規登録**
2. **代理店名** ／ **親代理店**「なし」（＝1次）／ **報酬率**（例 20）を入れて **登録する** → **紹介コード（6桁）** が自動で発行される
3. もう1つ、親代理店に 2 で作った代理店を選んで登録する（＝2次）。報酬率は **0%** と表示される
4. 自分のお店の **編集** →「管理設定」の **紐付け代理店** で、2次代理店を選ぶ（1次の下に2次がインデント表示）→ **更新**
5. 代理店管理の一覧で、その代理店の **「店舗数」** が増えていれば成功

## なぜ？

**Q. 代理店って？**
お店をサービスに紹介してくれる会社や人です。紹介してくれたお店で売上が出ると、**手数料の一部**が報酬として代理店に支払われます。

**Q. 1次と2次のちがいは？**
2次代理店は、1次代理店の下で動く代理店です。**報酬はすべて1次代理店に支払い、2次の取り分は1次から受け取る** 決まりなので、管理画面では2次の報酬率は 0% と表示されます（仕様です）。
→ [売上集計](http://localhost:3000/admin/sales) では、2次代理店経由のお店も「1次代理店」の欄に1次の名前が出ます（第10章のあとに確認）。

**Q. なぜ「表示名・コードで確認」が大事？**
代理店は名前が似ていることがよくあります。紐付けを間違えると、報酬が別の会社に計算されてしまいます。選ぶときは必ず **紹介コード** まで見ましょう。
