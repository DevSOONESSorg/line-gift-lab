# 第9章 代理店をつくって店舗に紐付ける

> 手順書 第9章に対応 ／ 使う画面：管理画面
>
> この章でわかること：代理店＝お店を紹介してくれる会社 ／ 1次・2次のしくみ ／ 報酬は「売上 × 報酬率」

## やること

1. [代理店管理](http://localhost:3000/admin/agents) → **新規登録**
2. **代理店名**、**親代理店**「なし」（＝1次）、**報酬率**（例 3）を入れて **登録する** → **紹介コード（6桁）** が自動で発行される
3. もう1つ、親代理店に 2 で作った代理店を選んで登録する（＝2次。報酬率は 0% になる）
4. クラブ アズールの **編集** →「管理設定」の **紐付け代理店** で、2次代理店を選ぶ（1次の下に2次がインデント表示）→ **更新**
5. 代理店管理で、その代理店の **店舗数** が増えていれば成功
6. 1次代理店の **詳細** を開き、「報酬サマリー」の **2次代理店経由** の店舗数を確認

### 構築の課題のお店では（構築ナビ 手順3）

構築ナビで選んだお店は、代理店を新しく作らなくてよいです。見るのは「**依頼書の紹介元と、紐付けが合っているか**」です。

1. 構築ナビの手順3に、依頼書の紹介元（代理店名と **紹介コード**）が出ます。「紹介元：なし」のお店もあります
2. 管理画面 → お店の **編集** →「管理設定」の **紐付け代理店** を見る
3. お店によって、スタート地点がちがいます

   | スタート地点 | すること |
   |---|---|
   | 出店登録のときに、もう正しく紐付いている | 紹介コードまで見て、合っていればそのまま |
   | まだ紐付いていない | 紹介コードまで同じものを選んで **更新** |
   | 紹介元が「なし」 | 何か選ばれていたら「紐付けなし」にして **更新** |

4. 合っていれば、構築ナビの手順3が「完了」になります。ちがう代理店を選ぶと「紐付けた代理店が依頼とちがいます」と出ます

## なぜ？

**Q. 代理店って？**
お店をサービスに紹介してくれる会社です。紹介してくれたお店で売上が出ると、報酬を支払います。

**Q. 報酬はどう計算する？**
**紐づけ店舗の売上 × 1次代理店の報酬率** です（手数料に対してではなく、売上に対して）。数えるのは「受取済み」「お礼済み」の注文だけです。
→ `app/Http/Controllers/Admin/AgentController.php` の `show()` と、`app/Models/Agent.php` の `rewardStoreIds()`（直接の店舗 ＋ 2次経由の店舗）を読んでみましょう。

**Q. 2次代理店の報酬率が 0% なのはなぜ？**
運営は **1次代理店にだけ** 報酬を支払い、2次の取り分は1次から受け取る決まりだからです（仕様）。だから2次経由のお店の売上は、1次代理店の報酬サマリーに入ります。

**Q. なぜ「紹介コードで確認」が大事？**
代理店は名前が似ていることがよくあります。紐付けを間違えると、報酬が別の会社に計算されてしまいます。選ぶときは必ず **紹介コード** まで見ましょう。
