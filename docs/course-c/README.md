# コースC：仕組みを読んで直せる

コースAで「何が起きているか」は見えるようになりました。コースCでは、この教材アプリの **Laravel のコード** を読んで、「なぜそう動くのか」を理解し、改修課題に取り組みます。

本番環境の管理画面も Laravel で作られています（画面のつくり、フォームの `_token`、`/admin/stores/{id}/edit` のようなURLの形が同じです）。ここで身につけたことは、そのまま実物のコードを読む力になります。

## 進め方

1. 各章の「読むファイル」を開いて、コメントを読む
2. 「確かめる」で、実際に動かして確認する（tinker・artisan コマンド・画面）
3. 「課題」をやる。**変更したら `git diff` を提出**
4. わからないことはAIに聞いてよい。ただし「なぜそうなるか」を自分の言葉で説明できるまで

| 章 | テーマ | 学ぶこと |
|---|---|---|
| [C0](C0-map.md) | Laravel の地図 | URL → ルート → コントローラー → モデル → 画面 の流れ。artisan・tinker |
| [C1](C1-state.md) | 注文の状態遷移 | enum、状態遷移表、トランザクション、履歴テーブル |
| [C2](C2-payment.md) | 決済と期限 | 与信と確定、スケジューラー、artisan コマンド |
| [C3](C3-files.md) | ファイルと署名付きURL | 公開しない保存場所、期限つきURL、アップロードの検証 |
| [C4](C4-security.md) | セキュリティ | CSRF、Webhook の署名、暗号化して保存、ログイン、IDトークン |
| [C5](C5-sql.md) | 集計と SQL | GROUP BY、月別手数料、代理店報酬 |
| [C6](C6-fallback.md) | 外部サービスとつなぐ設計 | フォールバック、タイムアウト、「本物のLINE」と「疑似LINE」の切り替え |
| [C7](C7-production.md) | 本番を触るときの約束 | 環境の分離、確認ダイアログ、見るだけの調べ方 |

## 準備

アプリを動かしたまま、別のターミナルで：

```bash
cd ~/Desktop/line-gift-lab
git checkout -b my-work          # 自分用のブランチを作る（あとで git diff を出しやすい）
docker compose exec app php artisan route:list
```

VS Code でフォルダを開いておくと読みやすいです。
