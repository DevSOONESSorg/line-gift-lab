# 用語集

| 用語 | 意味 | 教材で出てくる場所 |
|---|---|---|
| 公式アカウント（LINE公式アカウント） | お店や会社が持つLINEのアカウント。友だち追加してもらい、メッセージを送る | Manager |
| ベーシックID | 公式アカウントのID。`@123abcde` の形。友だち追加のリンクに使う | 第3章・第5章 |
| Manager（LINE Official Account Manager） | 公式アカウントの管理画面。応答設定・リッチメニュー・権限管理など | 第3・7・8章 |
| 管理者／運用担当者 | 公式アカウントの権限。管理者はすべて、運用担当者は日々の運用（メンバー追加はできない） | 第3章 |
| LINE Developers Console | 開発者向けの管理画面。プロバイダー・チャネル・LIFF・Webhook を設定する | 第4〜6章 |
| プロバイダー | Developers の中の「会社の箱」。チャネルはどれかの箱に入る。箱がちがうと同じ人でもユーザーIDがちがう | 第3章 |
| チャネル | LINEの機能を使うための「窓口」。Messaging API チャネルと LINEログインチャネルがある | 第3〜5章 |
| Messaging API | プログラム（bot）から公式アカウントのメッセージを送受信するしくみ | 第3・5・6章 |
| チャネルID | チャネルの番号（10桁） | 第5章 |
| チャネルシークレット | LINE社と自社だけが知っている合言葉。Webhook の署名の確認に使う。ネットには流さない | 第5・6章 |
| チャネルアクセストークン | LINE社にお願いするときに見せる通行証。長期トークンは再発行すると古いものが使えなくなる | 第5章 |
| Webhook | 「何か起きたらこのURLに知らせて」という登録。LINE社 → 自社サーバー | 第6章 |
| イベント | Webhook で届く出来事。follow（友だち追加）、message（メッセージ）、postback（ボタン）、unfollow（ブロック）など | 第6・7章 |
| 署名（X-Line-Signature） | Webhook の本文をシークレットで計算した値。本物のLINE社からの通知かを確かめる | 第6章 |
| Verify | Webhook URL に中身のないテスト通知を送り、200 が返るか確かめるボタン | 第6章 |
| ステータスコード | サーバーの答えの番号。200＝OK、401＝本人確認失敗、404＝見つからない、500＝サーバーのエラー | 第6章 |
| reply（返信） | Webhook で届いた replyToken を使う返事。1回だけ・約1分以内。無料の通数に数えない | 第7・10章 |
| push（送信） | こちらから送るメッセージ。友だちでないと届かない。無料プランは月の通数に上限がある | 第10章 |
| 応答メッセージ | LINE社が自動で返す定型文（Manager で設定）。bot とつなぐときはオフにする | 第7章 |
| 応答モード | Bot（プログラム・自動応答）かチャット（人が返事）か | 第7章 |
| リッチメニュー | トーク画面の下に出るメニュー。1枚の画像＋押せる四角（当たり判定） | 第8章 |
| postback | 押しても画面にメッセージを出さず、データだけ bot に届けるボタン | コースB B4 |
| LIFF | LINE の中で開く、自社のWebページ。`https://liff.line.me/{LIFF_ID}` で開く | 第4・8・10章 |
| LIFF ID | LIFF アプリの番号。`チャネルID-8文字` の形 | 第4・5章 |
| エンドポイントURL | LIFF ID を開いたときに、実際に表示される自社ページのURL | 第4章 |
| slug（スラッグ） | URL に入る「お店の住所」。一度決めたら変えない | 第1・4・6章 |
| ユーザーID | LINE の利用者の番号。`U` で始まる33文字。プロバイダーごとにちがう | 第1・10章 |
| 店舗管理者 | 出店登録したLINEの人。贈り物の「受け取る」を押せる | 第1・10章 |
| 仮押さえ（オーソリ）／確定 | カードの枠だけ確保しておく状態と、実際にお金を動かす状態 | 第10章 |
| 代理店（1次・2次） | お店を紹介してくれる会社。報酬は1次に支払い、2次は1次から受け取る | 第9章 |
| トンネル | インターネット → 自分のPC への一時的な入口（cloudflared） | コースB B3 |
